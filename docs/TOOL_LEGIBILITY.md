# MCP Tool Legibility Matrix

> Canonical audit and scoring matrix for Model Context Protocol (MCP) tools in `x402-mcp`.
> Scope: Evaluates runtime-decorated tools in `app/mcp_server.py` and canonical entries registered in `app/tools_registry.py`.
> Acceptance criteria per `docs/BOUNTIES.md`: Scored across **Outcome**, **When to use**, **Cost**, **Example**, and **Failure**.

---

## Global Invariants & Quota Envelope

Every public tool call executes through the chokepoint wrapper `_execute_tool(...)` in `app/mcp_server.py`.

- **Preemptive Quota Enforcement:** Call count and rate limits are decremented *before* executing expensive upstream or handler logic (`InMemoryQuotaStore` / Redis backed).
- **Free Tier Envelope:** `500 calls/month` total, `10 calls/minute` burst per caller `agent_id` (fallback `anonymous`). Exceeding returns structured `429` (`rate_limit_exceeded`).
- **Response Shape:** Free and query tools return standard envelope `{"data": ..., "meta": {"agent_id": ..., "tier": "free", "quota_remaining": ..., "upgrade_url": ...}}`. Paid tools emit standard `402 Payment Required` challenge payloads with `accepts[]` when unpaid, or facilitator settlement receipts when paid.
- **Fail-Safe Settlement:** Spender keys (`EVM_PRIVATE_KEY`) are never loaded on public seller nodes; tools that spend require explicit client-side key provisioning.

## Operator-Gated Extensions (MailRail Suite)

Per commit `aa961ff` and `docs/MAILRAIL-PUBLIC-SURFACE.md`, MailRail dispatch tools are intentionally restricted to authorized operators (`OPERATOR_ONLY_MCP_TOOLS`) to protect relay reputations and prevent abuse:

1. `mailrail.send`: Outbound agent message and receipt dispatcher. Requires bearer authentication; deduplicates by `event_id`.
2. `mailrail.status`: Health probe inspecting SMTP/Resend provider status and deliverability metrics.
3. `mailrail.inbound`: Webhook ingestion pipeline routing messages to the MailRail Postmaster agent with mention defusing.
