## Sequence (Non‑Negotiable)

Every bounty execution **must** follow exactly one of these two sequences.

### Standard Order (Spec → Delivery → Payment → Hash)

1. **Public spec** lives on a `bounty:` issue (this document or a child issue referencing it).
2. **Operator** delivers a **new file only** on the `master` branch (no modifications to existing files except those explicitly permitted by the issue).
3. **Counterparty** sends USDC on Base to `payTo` (address above) for the agreed amount.
4. **Operator** pastes the BaseScan transaction hash as a comment on the issue.
5. **Issue closes** only after the hash is present on the thread. No hash → no close.
